# 건강하지?! (Gungangazi)

예비 캡스톤 프로젝트로 시작한 “건강하지?!”는  
사용자의 건강 상태를 감정형 캐릭터 **'강하지'**를 통해 시각화하는  
**다마고치 기반 헬스케어 앱**입니다.

Flutter를 기반으로 모바일/웹 앱을 모두 지원하며,  
Spring Boot + AWS EC2 환경에서 서버와 데이터 처리를 수행합니다.

---

## 🐾 컨셉 및 핵심 기능


사용자의 건강 기록에 따라 강하지의 상태가 변합니다.

- 💤 수면 기록
- 💧 수분 섭취
- 💊 영양제 복용
- ❤️ 혈압 기록
- 🩸 생리 주기 기록
- 📅 개인 맞춤형 건강 달력

사용자는 캐릭터를 통해 자신의 건강 상태를 직관적으로 인식할 수 있으며,  
이를 통해 자연스럽게 자기관리를 유도합니다.

---

## 🛠️ 기술 스택 및 구조

| 구분         | 기술                                                                                 |
| ------------ | ------------------------------------------------------------------------------------ |
| **Frontend** | Flutter (모바일 + 웹 지원), Provider 상태관리, 반응형 UI                             |
| **Backend**  | Spring Boot, JWT 인증, Google Login 연동, SMTP+Redis 이메일 인증                     |
| **DevOps**   | AWS EC2 (Ubuntu), Nginx, GitHub Actions CI/CD                                        |
| **기타**     | Flask 기반 Rule-Based AI 진단 시스템 (현재 보류), SecureStorage / HttpOnly 쿠키 사용 |

---

## 주요 기술 및 구현

- Flutter 기반 웹/앱 통합 프로젝트 (1인 개발)
- JWT 기반 사용자 인증 흐름 구현 (로그인 → 토큰 저장 → 프로필 불러오기)
- Spring Boot 백엔드 연동 및 인증 API 설계
- Provider + ViewModel 구조로 상태관리 분리
- 실시간 Google 로그인 구현 (웹/앱 구분 대응)
- AWS EC2 + Nginx + CI/CD 자동 배포 구성
- Flask 기반 질병 예측 AI 모듈 (rule-based, 현재는 보류)

## 🎨 디자인 및 감성 요소

- **캐릭터 ‘강하지’는 직접 그림으로 구현**한 감정형 다마고치입니다.
- 사용자의 건강 상태에 따라 표정, 대사, 움직임이 변화합니다.
- 정서적 연결을 통해 **자기관리의 지속성**을 유도합니다.
