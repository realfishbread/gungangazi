ExerciseSession

class ExerciseSession : Parcelable

It specifies the exercise session. One or more exercise sessions can be included in one exercise data record. For instance, if a user performs a TRIATHLON multisport exercise, each session contains data for one of the three exercises performed during a specific time interval.
