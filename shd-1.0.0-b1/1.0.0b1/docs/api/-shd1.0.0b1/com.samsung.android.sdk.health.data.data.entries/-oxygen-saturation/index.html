OxygenSaturation

class OxygenSaturation : Parcelable

OxygenSaturation specifies a single record of blood oxygen in blood oxygen data.

This record includes the following:

  • The blood oxygen value as oxygenSaturation.

  • The lowest blood oxygen value as min.

  • The highest blood oxygen value as max.

  • The time when measurement started as startTime.

  • The time when measurement ended as endTime.
