Change

class Change<T : DataPoint?> : Parcelable

A differential sync change that represents a modification to a single record.

The change includes the following information:

  • The change type, which is either ChangeType.UPSERT or ChangeType.DELETE.

  • The time of the change as an Instant.

  • The uid of deleted data, or the DataPoint of updated data.
