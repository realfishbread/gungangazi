Device

class Device : Parcelable

Specifies the source device information that provides health data.

It includes:

  • id for a unique device ID

  • deviceType for what kind of a device it is, like DeviceGroup.MOBILE or DeviceGroup.WATCH

  • manufacturer name

  • model name

  • name customized by the user

id

val id: String

Retrieves the device ID. This ID is given to the device by Samsung Health. In general, it consists of 10 characters using the base62 format. This is not guaranteed to be the persistent ID for a physical device. For example, when reinstalling Samsung Health after it has been uninstalled, a new ID is given to the local device. So, this is a kind of logical device ID.
