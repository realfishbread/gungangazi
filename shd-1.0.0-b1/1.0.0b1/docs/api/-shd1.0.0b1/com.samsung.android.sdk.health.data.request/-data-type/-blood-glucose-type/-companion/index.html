val SERIES_DATA: Field<List<BloodGlucose>>

This field is for the continuous measurement of blood glucose levels. It is provided as a list of BloodGlucose measurements. Each BloodGlucose measurement has measurement time information and a measured value. If this field is null, it means that only one blood glucose value is included in the data. In this case, see GLUCOSE_LEVEL.
