@JvmField
val SERIES_DATA: Field<List<OxygenSaturation>>

This field is for the continuous measurement of blood oxygen levels. It is provided as a list of OxygenSaturation measurements. Each OxygenSaturation measurement has measurement time information and a measured value. If this field is null, it means that only one blood oxygen value is included in the data. In this case, see OXYGEN_SATURATION.
