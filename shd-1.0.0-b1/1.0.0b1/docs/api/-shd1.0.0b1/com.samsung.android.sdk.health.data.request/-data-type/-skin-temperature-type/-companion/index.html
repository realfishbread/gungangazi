@JvmField
val SERIES_DATA: Field<List<SkinTemperature>>

This field is for the continuous measurement of skin temperature. It is provided as a list of SkinTemperature measurements. Each SkinTemperature measurement has measurement time information and a measured value. If this field is null, it means that only one skin temperature value is included in the data. In this case, see SKIN_TEMPERATURE.
