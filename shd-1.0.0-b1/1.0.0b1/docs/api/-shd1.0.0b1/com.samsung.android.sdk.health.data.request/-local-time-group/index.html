LocalTimeGroup

class LocalTimeGroup : Parcelable

A grouped time interval with a pairing of LocalTimeGroupUnit and multiplier.

This means that the grouping is applied to intervals as much as the multiplier in local date and time format.

This can be used in aggregate requests. However, whether this group can be used is determined by the request builder provided by each data type.
