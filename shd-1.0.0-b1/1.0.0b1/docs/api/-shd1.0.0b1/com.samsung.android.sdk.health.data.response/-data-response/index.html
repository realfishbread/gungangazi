DataResponse

class DataResponse<T : Parcelable> : Parcelable

DataResponse represents a response coming from Samsung Health regarding the request.

This can hold all result data or a partial set. If the page size is set in the previous request and the number of result data is greater than that size, the SDK sends a page token in this response. The application can request to get the remaining data with this token. This class can be instantiated by its builder gotten from the .build() method, not directly by a constructor.
